**Install:** extract the full desktop archive and keep its bundled libraries beside the executable. Linux needs a compatible GTK3 runtime. Android development signing keys can differ between builds: export saved presets and scan drafts before uninstalling an older build, because uninstalling removes local app data.

These are development previews. Production signing, clean-device acceptance and other release work remain unfinished. Retain the bundled license and third-party notices when redistributing.
